# 코호트 선발 진행 지침

## 슬롯 트래킹
- 선발 인원이 변경되는 모든 응답의 첫 줄에 `[확정 N명 / 목표 M명 / 잔여 X자리]` 형식으로 현황을 출력한다.
- 목표 인원이 명시되지 않은 경우 사용자에게 먼저 확인한다.

## 비교표 선제 제공
- 분류 결과(A/B/C 등) 제시 후 잔여 슬롯 수가 확정되면, 사용자가 물어보기 전에 잔여 슬롯 수에 맞춘 우선순위 비교표를 즉시 제공한다.
- 비교표 형식: 이름 / 포지션(그룹 내 역할) / can_give 핵심 / 추천 순위
- 동일 포지션 후보가 2명 이상이면 차별점을 명시한다.

## 최종 확정 후 후속 체크리스트
- "최종 확정", "확정하겠다", "이걸로 가자" 등 최종 결정 발화 감지 시, 응답 말미에 미처리 후속 작업 체크리스트를 자동 출력한다.
- 체크리스트 예시:
  - [ ] 미선발 결제완료자 환불 처리 (N명)
  - [ ] 확정자 안내 (SMS / Discord 초대 등)
  - [ ] 미결제·폼만 제출자 참여불가 안내
  - [ ] 차기 기수 후보 명단 보관
