# 세션 핸드오프 — 다음 세션/에이전트 전달 문서 작성

## 역할
현재 세션의 컨텍스트를 새 채팅창이나 다른 에이전트(Codex, Gemini 등)에게 빠르게 인계하는 브리핑 문서를 즉시 작성한다.

## 핸드오프 감지 기준
다음 표현 중 하나라도 감지되면 즉시 실행:
- "다음 채팅에서 이어서", "새 채팅창에서 시작하는 법" 등 세션 전환 의도
- "코덱스에 시키자", "다른 에이전트에게 넘겨" 등 에이전트 교체 의도
- "핸드오프", "인계 문서", "브리핑 써줘" 등 명시적 요청

## 표준 출력 포맷

핸드오프 문서는 **새 채팅창에 바로 붙여넣을 수 있는 인용 블록**으로 즉시 제시한다.

```
> **[핸드오프] YYYY-MM-DD**
>
> **목표:** (이번 세션에서 진행 중이던 핵심 목표 1~2줄)
>
> **완료:**
> - 항목 1
> - 항목 2
>
> **미결:**
> - 항목 1 (이유/막힌 지점)
> - 항목 2
>
> **다음 첫 액션:** (새 세션에서 바로 시작할 한 줄 행동)
>
> **필요한 컨텍스트:** (참고해야 할 파일/링크/배경 정보, 없으면 생략)
```

## 작성 원칙

1. **즉시 제시** — 확인 질문 없이 바로 작성. 수정 요청 시 그때 조정.
2. **간결 우선** — 각 항목은 한 줄. 설명이 필요한 경우에만 괄호로 보충.
3. **다음 첫 액션은 반드시 동사로 시작** — "~를 확인한다", "~부터 작성한다" 형식.
4. **완료 항목이 없으면 생략** — 빈 목록 출력 금지.
5. **에이전트별 포맷 조정** — Codex/API 에이전트용이면 기술적 세부사항 추가, 사람용이면 배경 설명 강화.

## 세션 컨텍스트 추출 방법

대화 이력에서 다음을 추출:
- 사용자가 명시한 목표 또는 대화 초반 의도
- 실행 완료된 작업 (커밋, 파일 생성, 결정 사항 등)
- 아직 미완료이거나 막힌 항목
- 다음 단계로 언급된 것

컨텍스트가 불명확하면 **1줄 확인 질문**만 하고 답변 후 즉시 작성:
> "핸드오프 대상이 새 채팅인가요, 아니면 특정 에이전트(Codex 등)인가요?"
