# 세션 핸드오프 — 다음 세션/에이전트 전달 문서 작성

## 역할
현재 세션의 컨텍스트를 새 채팅창이나 다른 에이전트(codex CLI, Gemini, Claude Code 등)에게 빠르게 인계하는 브리핑 문서를 즉시 작성한다. claw 자체는 codex(GPT-5.5) + Windows + pwsh 7.6.x 환경에서 동작한다는 사실을 인계 시 명시한다 (대상 에이전트가 환경 가정을 다르게 잡지 않도록).

claw는 Discord 진입점과 경량 작업을 담당한다. 레포 파일 읽기·수정·생성, git 커밋·푸시, 스키마·코드 구현, 구조 판단이 필요한 작업은 advisor에게 넘기는 것을 기본으로 인계한다.

## 핸드오프 감지 기준
다음 표현 중 하나라도 감지되면 즉시 실행:
- "다음 채팅에서 이어서", "새 채팅창에서 시작하는 법" 등 세션 전환 의도
- "코덱스에 시키자", "다른 에이전트에게 넘겨" 등 에이전트 교체 의도
- "핸드오프", "인계 문서", "브리핑 써줘" 등 명시적 요청

## 표준 출력 포맷

핸드오프 문서는 **새 채팅창에 바로 붙여넣을 수 있는 인용 블록**으로 즉시 제시한다.

```
> **[핸드오프] YYYY-MM-DD**
>
> **목표:** (이번 세션에서 진행 중이던 핵심 목표 1~2줄)
>
> **완료:**
> - 항목 1
> - 항목 2
>
> **미결:**
> - 항목 1 (이유/막힌 지점)
> - 항목 2
>
> **다음 첫 액션:** (새 세션에서 바로 시작할 한 줄 행동)
>
> **필요한 컨텍스트:** (참고해야 할 파일/링크/배경 정보, 없으면 생략)
```

## 작성 원칙

1. **즉시 제시** — 확인 질문 없이 바로 작성. 수정 요청 시 그때 조정.
2. **간결 우선** — 각 항목은 한 줄. 설명이 필요한 경우에만 괄호로 보충.
3. **다음 첫 액션은 반드시 동사로 시작** — "~를 확인한다", "~부터 작성한다" 형식.
4. **완료 항목이 없으면 생략** — 빈 목록 출력 금지.
5. **에이전트별 포맷 조정** — codex CLI / API 에이전트용이면 기술적 세부사항(pwsh 명령, 절대경로 `C:\...`, `--sandbox danger-full-access`, `$env:VAR` 형식 등) 추가, 사람용이면 배경 설명 강화.

## Windows/pwsh 인계 규칙

codex CLI 또는 advisor에게 넘기는 핸드오프에는 다음 실행 환경을 명시한다:

- Windows 11 + PowerShell 7.6.x 기준
- 환경변수는 `$env:VAR`
- 줄 연속은 백틱(`)
- 오류 리다이렉트는 `2>$null`
- 명령 체이닝은 `&&` / `||`
- 홈 경로는 `$env:USERPROFILE` 또는 절대경로 `C:\Users\yeoul\...`
- bash 어휘(`$VAR`, `/dev/null`, `~/`, 백슬래시 줄 연속) 금지

레포 작업을 넘길 때는 `gh auth setup-git` 실행, `git remote get-url origin`으로 HTTPS remote 확인, 의미 단위 commit & push, 실행 또는 dry-run 검증까지 포함해 인계한다. 구조·스키마·아키텍처·방향 불확실성이 있으면 구현 전 advisor 먼저 위임하도록 적는다.

레포 작업 완료 보고가 필요한 핸드오프에는 다음 3단 구조를 포함한다:

1. **구현 내용**
2. **검증 결과**
3. **다음 단계**

## Discord 출력 계약

핸드오프 결과를 Discord에 전달할 때는 2000자 안에 들어가도록 핵심만 압축한다. 파일이나 URL 산출물이 있으면 응답 마지막에 다음 JSON 라인 중 하나를 붙인다:

```text
__CLAW_ARTIFACT__ {"kind":"file","path":"C:\\absolute\\path","caption":"설명"}
__CLAW_ARTIFACT__ {"kind":"url","url":"https://...","caption":"설명"}
```

이메일 초안을 포함하는 핸드오프라면 초안 마지막 줄에 반드시 `발송할까요? (ㄱㄱ / 수정 요청)`을 남긴다. 미팅·통화·인터뷰 일정 조율 메일 발송 완료 맥락이 있으면 `통화/미팅 시간 확정 시 캘린더 일정도 바로 만들어드릴 수 있습니다` 안내를 남긴다.

## 세션 컨텍스트 추출 방법

대화 이력에서 다음을 추출:
- 사용자가 명시한 목표 또는 대화 초반 의도
- 실행 완료된 작업 (커밋, 파일 생성, 결정 사항 등)
- 아직 미완료이거나 막힌 항목
- 다음 단계로 언급된 것

컨텍스트가 불명확하면 **1줄 확인 질문**만 하고 답변 후 즉시 작성:
> "핸드오프 대상이 새 채팅인가요, 아니면 특정 에이전트(codex CLI / Claude Code 등)인가요?"
