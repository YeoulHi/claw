# SMS·카카오톡 초안 작성 가이드

## 처리 경계
- 단순 SMS·카카오톡 초안, 짧은 답장, 톤 조정은 claw가 즉시 처리한다.
- 레포 파일, RAW.md, 고객 기록, 프로젝트 문서, 대량 명단 파일을 읽어야 하면 advisor에게 위임한다.
- 사용자가 파일 경로·프로젝트 기록·스키마·코드 수정까지 요구하면 문자 초안을 만들기 전에 advisor 위임 사실을 한 줄로 알린다.

## Step 0: 채널 식별
문자(SMS) 또는 카카오톡 초안 요청임을 확인한다. 이 skill은 이메일과 별개로 동작한다.

## Step 1: 사용자 톤 캘리브레이션
초안 작성 전 현재 대화 히스토리에서 사용자가 실제로 발송한 SMS·카카오 메시지를 찾아 스타일을 추출한다. 레포의 RAW.md, 첨부, 로그 파일 파싱이 필요하면 advisor에게 위임한다. Windows 경로는 절대경로 `C:\...` 형식을 사용한다.

추출 포인트:
- 이모지 사용 여부 및 빈도 (예: 🙂 🥲 사용)
- 경어체 수준 (격식체 vs 친근한 경어체)
- 문장 길이 (짧게 끊기 vs 이어쓰기)
- 인사말·호칭 패턴 (안녕하세요 팀장님 / 대표님 등)

## Step 2: 스타일 적용
추출한 스타일을 초안에 그대로 반영한다.

**기본 스타일 (히스토리 없을 때):**
- 친근한 경어체 사용
- 이모지 1-2개 포함 (🙂 😊 등)
- 2-3문장 이내로 짧게
- 요청 사항은 명확하게 한 문장으로
- 부정 표현 대신 긍정 우회 ("못 찾겠습니다" → "전달받은 것이 없는 것 같네요")

## Step 3: 출력 형식
설명 없이 초안만 단독으로 구분선(---) 안에 출력한다. 복사해서 바로 사용 가능하도록.
- 여러 건을 보고할 때는 각 건마다 채널·수신 시각·연락처·문의 원문을 생략하지 않는다.
- 파일 또는 URL 산출물을 만들었으면 최종 응답 끝에 claw artifact JSON을 붙인다.
  - 파일: `__CLAW_ARTIFACT__ {"kind":"file","path":"C:\\절대\\경로","caption":"설명"}`
  - URL: `__CLAW_ARTIFACT__ {"kind":"url","url":"https://...","caption":"설명"}`

## 다건 발송 — 멀티 에이전트 활용
- 수신자별로 톤·문구 미세조정이 필요한 다건 발송이면 codex의 `multi_agent=true`를 활용해 후보별 초안을 병렬 생성하고, 최종 출력에서는 수신자별 블록(`### {수신자}` + ---)으로 정렬한다.

## 실행·검증 규율
- 문자/카카오 초안만 작성한 경우 별도 셸 검증은 생략하고, 최종 보고에 "검증: 복붙용 구분선 출력 확인"을 포함한다.
- 파일 생성·대량 발송 스크립트·반복 워크플로우를 새로 만들거나 수정한 경우 PowerShell 7.6 기준으로 dry-run 또는 실행 검증을 직접 수행한다.
- 레포 변경을 수행했다면 의미 단위로 commit 후 `gh auth setup-git`, HTTPS remote 확인, `git push` 순서로 진행한다. 실패하면 강행하지 말고 보고한다.
- 반복 가능한 문자/카카오 발송 패턴이 새로 생기면 관련 skill 업데이트를 먼저 제안한다.
